# Book source format

Each `content/book/<locale>.md` file holds the full text of *Pravoslávna misia
medzi Rómami na strednom Slovensku* (Martin Halík, Prešov 2023) in one
language. `sk.md` is the original; every other file is a translation of it and
must keep the **same structure** (same headings in the same order, same
footnote numbers, same tables).

`scripts/build-ebooks.mjs` turns these files into EPUB 3 and PDF. The title
page, copyright page and table of contents are generated by the script from
`lib/data/book.ts` — do **not** write them in the Markdown.

## Supported syntax (nothing else)

| Syntax | Meaning |
|---|---|
| `# Title` | Part / top-level section. Starts a new EPUB file. Used for: Foreword, Introduction, the three parts (Theory and History, Practice, Conclusion), Bibliography. |
| `## 1.1. Title` | Chapter. Starts a new EPUB file and appears in the table of contents. Keep the original number prefix. |
| `### Title` | Subsection inside a chapter (appears in the TOC, nested). |
| blank-line separated text | Paragraph. One paragraph = one line. |
| `> text` | Block quotation (Bible verses, quoted passages). |
| `> — Name, Source` | When the last line of a quote starts with `— `, it is rendered as the attribution. |
| `- item` | Bulleted list item. |
| `1. item` | Numbered list item (only at line start, followed by a space and **no** further digits — `1.1. Title` is only valid after `##`). |
| `\| a \| b \|` | Pipe table. First row = header, second row = `\|---\|---\|`. |
| `*text*` / `**text**` | Italic / bold. |
| `[^7]` | Footnote reference. Numbers are unique and sequential across the **whole book** (1…N). |
| `[^7]: text` | Footnote definition. Put it on its own line directly after the paragraph that references it. |
| `<https://…>` | Bare link. |
| `---` | Scene break (centered ornament). |

## Rules

- Straight text only — no HTML.
- Use typographic quotes appropriate to the language („…“ for sk/cs/de/sr/mk/ro, “…” for en, «…» for ru/el).
- No hyphenation artifacts (`pre- tože` → `pretože`), no page numbers, no running headers.
